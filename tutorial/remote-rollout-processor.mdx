If you already have an agent, you can reuse your existing codebase by
integrating with `eval-protocol`'s `RemoteRolloutProcessor`.

`RemoteRolloutProcessor` delegates rollout execution to a remote HTTP service
that you control. It's useful for offloading rollouts to your existing agent
codebase by wrapping it in an HTTP service.

> **Module**: [`eval_protocol/pytest/remote_rollout_processor.py`](https://github.com/eval-protocol/python-sdk/blob/main/eval_protocol/pytest/remote_rollout_processor.py)

    ```python request_model.py
    from __future__ import annotations
    from typing import Any, List, Literal, Optional
    from pydantic import BaseModel, Field, ConfigDict, ValidationError
    import json

    class Message(BaseModel):
        role: Literal["system", "user", "assistant", "tool"]
        content: str

    class FunctionDefinition(BaseModel):
        name: str = Field(pattern=r"^[a-zA-Z0-9_-]{1,64}$")
        description: Optional[str] = None
        # JSON Schema for the function parameters; keep flexible
        parameters: Optional[dict[str, Any]] = None

    class Tool(BaseModel):
        type: Literal["function"] = "function"
        function: FunctionDefinition

    class Metadata(BaseModel):
        # allow extra metadata keys
        model_config = ConfigDict(extra="allow")
        invocation_id: str
        experiment_id: str
        rollout_id: str
        run_id: str
        row_id: str

    class InitRequest(BaseModel):
        model_config = ConfigDict(extra="forbid")
        rollout_id: str
        model: str
        messages: List[Message]
        tools: Optional[List[Tool]] = None
        metadata: Metadata
        num_turns: int = Field(ge=1)

    if __name__ == "__main__":
        payload = {
            "rollout_id": "rll_ijkl",
            "model": "openai/gpt-4o",
            "messages": [{"role": "user", "content": "Hello"}],
            "tools": [
                {
                    "type": "function",
                    "function": {
                        "name": "get_weather",
                        "description": "Get the weather for a city",
                        "parameters": {
                            "type": "object",
                            "properties": {
                                "city": {"type": "string"},
                                "unit": {"type": "string", "enum": ["c", "f"]}
                            },
                            "required": ["city"]
                        },
                    },
                }

                "run_id": "run_123",

        except ValidationError as e:
            print("Validation error:\n", e)
    ```

## Metadata piggyback

If your remote service calls a provider that accepts request `metadata` (e.g., LiteLLM/OpenAI), forward the identifiers for traceability:

- `invocation_id`
- `experiment_id`
- `rollout_id`
- `run_id`
- `row_id`

These appear in `EvaluationRow.execution_metadata` and `input_metadata.row_id` to enable end-to-end correlation across evaluations, logs, and traces.

## Usage

Assuming you have a server that implements the above API contract running at
`https://my-remote-evaluator.example.com`, you can use the following code to run
rollouts:

```python
from eval_protocol import (
    evaluation_test,
    DynamicDataLoader,
    RemoteRolloutProcessor,
)

def fetch_trajectories(invocation_id: str) -> list[EvaluationRow]:
    adapter = create_langfuse_adapter()
    return adapter.get_evaluation_rows(invocation_id=invocation_id, metadata={"agent": "web-search"})

def create_output_data_loader(invocation_id: str) -> DynamicDataLoader:
    return DynamicDataLoader(
        generators=[lambda: fetch_trajectories(invocation_id)]
    )

@pytest.mark.parametrize("completion_params", [{"model": "openai/gpt-4o"}])
@evaluation_test(
    data_loaders=[InlineDataLoader(messages=[[Message(role="user", content="Hello")]])],
    rollout_processor = RemoteRolloutProcessor(
        remote_base_url="https://my-remote-evaluator.example.com",
        output_data_loader=create_output_data_loader,
    )
)
def test_remote_http(row: EvaluationRow) -> EvaluationRow:
    # evaluate the row
    return row
```
